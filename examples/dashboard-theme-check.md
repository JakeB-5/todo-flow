# 대시보드 테마 브라우저 검증

이 절차는 dashboard-dark-mode의 theme-switch, theme-surfaces, theme-contract를 검증한다. 데이터는 모두 합성이며 실제 프로젝트에서 실행하지 않는다. Node 집중 테스트는 기존 명령 `node --test tests/dashboard_i18n.test.cjs`에 포함된다. 팔레트 수치 테스트만으로 실제 브라우저 검증을 대체하지 않는다.

## 준비

후보 체크아웃에서 새 임시 상태 경로를 사용한다.

```sh
uv run python scripts/dashboard_fixture.py --state /absolute/new-theme-demo --language en
uv run todo-flow --state /absolute/new-theme-demo serve --port 8766
```

브라우저에서 `http://127.0.0.1:8766`을 연다. 해당 origin의 `todo-flow.theme`만 삭제하고 새로고침하여 기본 밝은 테마를 확인한다. 다른 저장 키는 삭제하지 않는다. 후보 HEAD, 브라우저 버전, viewport, 언어, 테마, 경로와 결과를 검증 기록에 남긴다.

## 동작과 상태 보존

1. 테마 선택기를 Tab으로 이동해 방향키로 밝게/어둡게 전환한다. 두 선택지와 접근성 이름을 en/ko/ja/zh-CN에서 확인한다.
2. 어둡게 선택 후 TODO → 완료 보관함 → Activity → Watch → 트랙 상세를 탐색하고 새로고침한다. 선택한 테마가 유지되어야 한다. 밝게도 반복한다.
3. TODO에서 검색·필터·정렬과 트랙 선택을 유지한 채 전환한다. Activity에서 판단 답변 초안을 입력하고 선택한 트랙·작업·펼친 상세를 유지한 채 전환한다. 입력값과 커서 선택, URL, 선택한 항목, 스크롤 및 언어가 바뀌지 않아야 한다.
4. 전환 전후 네트워크 기록에서 테마 전환으로 발생한 요청이 없는지 확인한다. 기존 주기적 GET 폴링과 구별한다. POST 및 문서 iframe 재요청이 없어야 한다. iframe 노드와 contentWindow의 동일성 및 작성 문서 내부 모습을 비교한다.
5. 별도 브라우저 컨텍스트의 페이지 초기화 스크립트에서 localStorage 접근 또는 getItem/setItem이 예외를 던지게 한다. 페이지 진입과 두 테마 전환이 계속 동작해야 한다. 읽기 실패는 밝게 시작하며, 쓰기 실패는 현재 페이지 선택을 유지한다. 실제 저장소 차단을 설정하기 어렵다면 Node의 access/read/write 실패 테스트 결과와 그 한계를 함께 기록한다.

## 화면과 대비

1280×900과 390×844에서 두 테마와 네 언어를 확인한다. 상단의 테마·언어 선택기, 연결 표시, 새로고침 버튼 및 목록의 검색·필터·선택 조작부가 잘리거나 겹치지 않아야 한다. 긴 옵션은 드롭다운을 열어 전체 이름을 확인한다.

다음 상태를 각각 화면 캡처한다.

- TODO 정상 목록, 체크된 행, hover, 키보드 focus, 선택 전 비활성 실행 명령 버튼
- 일치하지 않는 검색어의 빈 목록 및 완료 보관함의 정상/빈 검색 결과
- Activity 작업 목록, 선택한 작업의 상세 외곽, 판단 답변 입력과 focus
- Watch 카드 및 트랙 상세 외곽, 근거 표시
- 연결 실패 안내와 경고 배지: 합성 서버의 API 요청만 잠시 차단하여 오류 표시를 확인하고 복구한다

실제 렌더링된 대표 본문·보조문구·배지·입력 placeholder·버튼 텍스트의 전경색과 최종 배경색을 수집한다. 투명 배경은 불투명 조상까지 합성하며 iframe 내부는 검사 대상에서 제외한다. 본문과 보조문구는 4.5:1 이상, 입력·선택기 등 필수 경계 및 키보드 focus는 인접 배경에 대해 3:1 이상이어야 한다. hover/선택/경고/오류 배경에서도 반복한다. 브라우저 개발자 도구의 접근성 대비 검사 또는 아래 계산식을 사용하고, 선택자·상태·실제 색·계산값을 기록한다.

```js
function contrast(rgbA, rgbB) {
  const luminance = rgb => rgb.map(v => v / 255)
    .map(v => v <= 0.04045 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4)
    .reduce((sum, v, i) => sum + v * [0.2126, 0.7152, 0.0722][i], 0);
  const values = [luminance(rgbA), luminance(rgbB)].sort((a, b) => b - a);
  return (values[0] + 0.05) / (values[1] + 0.05);
}
```

검증 후 합성 서버를 종료한다. 검증하지 못한 항목은 통과로 기록하지 않는다. 브라우저 결과와 전체 자동 검증이 준비된 동일 HEAD를 독립 리뷰에 제공한다.
